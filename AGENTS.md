# Repository-instruksjoner

- Skriv all produksjonskode, tester og utviklingsverktøy i Swift. GitHub YAML og annen nødvendig konfigurasjon er tillatt.
- Analyser og funn deles kun i samtalen. Ikke opprett analyserapporter, vurderingsrapporter eller funnlister i repositoryet, heller ikke som ignorerte filer.
- Vedlikehold produktdokumentasjon og test-/integrasjonsveiledning. Ikke påstå verifisert leverandørintegrasjon uten faktisk test.
- Bruk Apple-rammeverk og vår egen Networking-pakke. OIDC-protokollkode vedlikeholdes her; kryptografiske primitiver skal leveres av Security/CryptoKit. Ikke legg til tredjeparts-SDK-er eller JWT-biblioteker. Behold reelle signatur- og protokolltester.
- Ingen passord, client secrets, rå tokenlogger, ferdige skjermer, appnavigasjon eller DesignSystem-avhengighet.
